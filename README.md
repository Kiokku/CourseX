# CourseX

**把课程学成自己的知识。**

CourseX 是一个本地优先的课程学习工作台，将视频、课件、AI 问答和知识画布放在同一个学习空间。你可以边学边提问，把值得保留的解释、疑问和验证结果整理成卡片，再通过引用和连线建立自己的知识网络。

它关注一次学习最终留下了什么：能否用自己的话解释，是否有证据支持，下次遇到问题时能否找到并继续使用。

## 愿景

我们希望 CourseX 成为个人长期使用的学习空间：学习围绕问题展开，理解通过实践检验，成果由自己保存和掌握。

一门课结束后，留下的不只是播放进度，还有可以回访的思考、可追溯的依据，以及能够连接到下一门课的知识。随着学习积累，CourseX 希望帮助你从消费内容走向建立自己的理解体系。

## 你可以用 CourseX 做什么

### 在同一个空间里学习

- 按课程和章节浏览本地资料，同时观看视频、阅读 Markdown 课件与图片。
- 调整视频和课件的显示比例，使用倍速、全屏或浏览器支持的画中画。
- 自动保存播放位置，回到章节时继续学习。

### 带着问题与 AI 讨论

- 围绕当前课件提问，接收流式回答，随时停止生成或继续追问。
- 按章节保留对话，把完整问答或选中的回答片段保存到画布。
- 将回答提炼成可编辑的知识草稿，结合自己的验证继续完善。

### 把理解沉淀到画布

- 每个章节拥有自己的主画布，也可以新建独立草稿画板。
- 用问题、笔记、结论和证据卡片整理思考，移动、缩放、连线并插入图片。
- 保存课件选文，记录网页、代码提交、测试结果等依据，区分待验证和已验证的内容。
- 搜索已保存的卡片，通过跨章节引用连接相关知识，并跳回原卡片查看。

### 保存、带走和恢复学习成果

- 学习数据与画布图片保存在运行 CourseX 的电脑上。
- 将当前课程或全部成果导出为结构化 ZIP，卡片正文可作为 Markdown 阅读，布局单独保存。
- 按个人备份或分享用途选择内容；导出包不包含模型配置、课程原视频、完整课件或完整聊天历史。
- 导入同版本成果包时先预览，再新增无冲突内容，保留已有数据。

## 开始使用

### 1. 准备课程资料

获取本仓库代码后，在项目根目录创建或编辑 `.env`，将 `COURSEX_LIBRARY` 设置为自己已创建的课程资料目录。

资料按“课程 → 章节”两层文件夹组织。每个章节放置名为 `视频.mp4` 的视频、名为 `课件.md` 的 Markdown 课件，至少提供其中一种。课程和章节的文件夹名称会显示为标题。

课程资料需自行准备，仓库不附带课程视频或课件。

### 2. 启动 CourseX

准备 Node.js 22.12 或更高版本，在项目根目录执行：

```bash
npm install
npm run dev
```

在浏览器打开 [http://localhost:4310](http://localhost:4310)。停止服务时，在终端按 `Ctrl+C`。

新增资料后，在页面刷新课程目录；修改课程目录配置后，需重新启动服务。

### 3. 完成一次学习

1. 选择一个章节，观看视频或阅读课件，记下自己想弄清楚的问题。
2. 打开章节主画布，用知识卡片记录解释、疑问和实践结果。
3. 为重要结论补充来源与证据，验证后再更新卡片状态。
4. 等待页面提示“已保存到本地”，之后可通过搜索或章节入口继续回访。

### 4. 按需启用 AI 问答

在页面“模型设置”中填写供应商的 OpenAI 兼容接口 Base URL、模型名和 API Key。配置完成后，即可在“课节问答”中围绕课件讨论。

AI 请求会将当前课件、最近的对话上下文和本次问题发送到你配置的模型服务。当前问答使用文本上下文，不直接理解视频声音或画面；AI 提炼的内容默认保持待验证状态。

### 5. 备份或恢复成果

点击“导出”，选择课程范围和需要保留的内容。恢复时点击“导入”，选择成果包，检查预览后确认新增。

章节恢复需要匹配原有课程与章节的稳定身份；迁移课程时请完整保留课程目录及其中自动生成的身份文件。成果包不代替课程原文件和应用全部数据的完整备份。

详细规则见 [导出说明](docs/export.md)和[导入恢复说明](docs/import.md)。

## 运行与访问

CourseX 需要保持服务运行。其他设备可在同一可信局域网中，通过启动终端显示的网络地址访问同一份学习数据。当前版本适合个人使用，未提供账号认证或实时多人协作，请勿直接向公网开放。

生产运行前需配置有效的 `TLDRAW_LICENSE_KEY`，然后执行：

```bash
npm run build
npm start
```
