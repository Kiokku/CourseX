# 同版本学习成果恢复

右上角“导入” → 选择 CourseX 导出的 ZIP → “预览导入” → 检查各项结果 → “确认新增” → “刷新并查看”。预览不修改学习数据或图片文件。取消预览不产生恢复内容。

## 恢复范围

支持导出协议 schemaVersion 1、与当前安装相同的 tldraw 文档 schema。恢复包内章节主画布绑定、卡片正文与原时间、证据、主动保存的问答快照、布局、所选本地图片；个人包包含的视口和播放进度也会恢复。独立草稿作为独立画板恢复。卡片 ID 与章节/画板 ID 保留，图片生成新的本地文件名，画布中的引用随之转换。

问答来源仍是保存时的不可变摘录，不会追加到课节完整聊天；未知历史时间继续显示未知。课件引用保留原文片段及摘要，不用当前版本的课件替换历史来源。导入快照不构成对笔记结论或来源真实性的重新验证。

导出时未包含、已清理或已省略的内容无法补回，包括模型配置、凭据、完整聊天、原视频与完整课件。分享包只能恢复实际保留的部分。导出 ZIP 仍不等于部署电脑的完整备份。

## 匹配与冲突

- 章节按课程 ID 和章节 ID 匹配，目录名称不作为匹配依据。恢复到另一台机器前，请一并复制课程目录及其中的 `.coursex-id.json`，然后配置资料目录。
- 找不到对应 ID（包括 `unassigned` 中仍失联的章节），预览显示“章节未匹配”并跳过；不创建虚假的课程目录，不按同名课程强行关联。先恢复课程及身份文件后可重新导入。
- 以整个章节或独立草稿为最小单位。主画布绑定、卡片 ID、证据/摘录 ID、画板 ID 或将被写入的播放进度存在冲突时，保留本地数据，跳过整个项目。
- 没有画布、卡片和进度的章节显示“无学习数据”，不会建立空绑定。其他无冲突项目仍可新增。首版不提供覆盖、重命名 ID 或字段合并。
- 确认时重新校验 ZIP 与当前可新增项目；预览之后若发生相关并发修改，要求重新预览，不能静默覆盖。互不相关的课节聊天、设置修改不使预览失效。

## 校验与提交

ZIP 最大 100 MB；最多 10000 个文件、单文件最多 20 MB、解压总计最多 200 MB。超限请按课程分别导出。仅接受规范包路径和 UTF-8 文本，拒绝重复路径、路径越界、未识别文件与清单不一致。

校验卡片 Markdown 元数据、稳定 ID、实体归属、来源索引、tldraw 对象类型及属性、形状父节点/连接/卡片/图片引用、视口页面与图片字节大小和 SHA-256。错误返回对应文件或对象；未知 schema/对象不会被静默丢弃。图片和清单摘要只能检查一致性，不是包来源的数字签名。

外部 HTTP(S) 图片仍为外部引用，不保证离线可用。内嵌图片仅接受 PNG/JPEG/WebP/GIF data URL。包内图片不覆盖已有图片，只有实际新增画布使用的图片会写入；预览不会下载外部文件。保存学习数据失败会清理本次暂存图片，并保留原状态。进程被强制终止时可能遗留无引用图片文件，但已提交状态不会引用写入一半的图片。

确认使用同一个串行 Store 事务提交新画布、主画布绑定、语义内容与进度；不支持多个服务进程同时操作同一个数据目录。恢复后请用页面上的“刷新并查看”重新加载画板列表。
