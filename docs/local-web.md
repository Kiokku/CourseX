# CourseX 本地 Web 使用与网络方案

## 启动

需要 Node.js 22.12 或更高版本。本机课程库已迁移到 `/Volumes/Steam/CourseXLibrary`，通过 `.env` 中的 `COURSEX_LIBRARY` 指定。应用和 `./download.sh` 共用此配置；未配置时回退到项目的 `library/`。

```bash
cd /Volumes/Steam/ProjectLibrary/CourseX
npm install
# 首次配置：复制 .env.example 为 .env，并设置 COURSEX_LIBRARY
# 已有 .env 时保留原文件
npm run dev
```

打开 `http://localhost:4310`。当前交付先以开发模式运行，方便完成 tldraw 许可配置前的开发验证；这不等同于 tldraw 的生产部署验收。停止服务按终端中的 Ctrl+C。

需要调整端口、资料目录、数据目录或许可时，将 `.env.example` 复制为 `.env`，修改对应字段并重新启动。项目启动命令自动读取 `.env`。

## 学习与笔记

- 左侧以课程库下文件夹名显示课程，已有课程清单决定课节顺序。点击刷新可发现新增课程。
- 中间同时显示视频、Markdown 课件和本地图片。拖动两者之间的分隔条可调高度，也可聚焦分隔条后按上下方向键。
- 视频支持浏览器原生播放、定位、全屏和倍速。播放进度每约 5 秒及暂停、定位、切课时保存。
- 右下角「课节问答」展开悬浮窗口，点击收起按钮恢复阅读空间；收起时保留输入和继续生成，问答按课节保存。Enter 发送，Shift+Enter 换行；回答生成中可停止。
- 浏览器支持时，可点击「画中画」或使用原生视频画中画入口；进入后页面播放器和分隔条收起，课件占满学习区域，退出后恢复原高度。
- 右侧默认恢复当前课节的主画布；尚未创建时点击“创建章节主画布”或“打开当前章节主画布”，重复打开不会新增副本。原画板仍以草稿保留，可从下拉列表选择，或点击“新建草稿”。支持命名和展开。
- 主画布点击“＋ 知识卡片”，可编辑类型、标题、正文和待验证/已验证状态；点击“完成”回到画布。卡片可移动、缩放、连线，选中后通过 tldraw 删除；本次页面会话内可撤销删除。完整正文从卡片“编辑”入口阅读。
- 编辑后约 0.7 秒自动保存，也可点击“立即保存”。切换课节和画板前等待保存；标题为空或保存失败时保留当前编辑。先等“已保存到本地”再关闭页面。
- 课节问答中，每条回答可“保存问答到画布”或“提炼为草稿”。展开“选取回答片段”后，在文本框中仅保留需要的连续原文；支持切回完整回答。保存会自动打开或创建当前课节主画布，并保留问题、回答、时间和来源上下文。提炼调用当前模型，结果保持待验证，可继续编辑；不会自动把全部聊天放入画布。
- 卡片“来源与证据”支持添加、编辑、移除网页/源码、Git commit、文件路径、测试结果和课程章节引用，可注明 React/代码版本。网页链接可直接打开，路径和测试结果保留为文本。带问答来源的卡片可查看保存时的原消息；卡片正文编辑不改写来源快照。
- 在课件中选择局部文字，点击“保存选文到画布”，可创建待验证草稿并保留来源。片段上限 2000 字，不接受完整课件。新卡片提交前若课件变化，需要重新选择。
- 右上角“导出”可下载当前课程或全部学习成果的 ZIP，支持个人备份包/分享包及问答、图片筛选。正文与布局分开，默认排除配置、凭据及课程原文件。分享包还默认排除问答、图片和课件摘录。详细范围见 [导出说明](export.md)。
- 右上角“导入”支持同版本 ZIP，先校验和预览，再确认新增。已存在的数据整章/整张草稿跳过，不覆盖；章节需要匹配课程目录里的稳定 ID，导入成功后刷新查看。资源、来源和恢复边界见 [导入说明](import.md)。
- 窄屏打开笔记区域时暂停显示问答浮窗，收起笔记区域后可继续问答。
- 插入画板的 PNG、JPEG、WebP、GIF 图片保存在部署电脑，单图上限 20 MB。P0 不提供视频附件上传。
- 保存状态为“已保存到本地”后再关闭页面。数据来自部署电脑，不是当前浏览器独立存储；另一设备重新打开可以读取已保存内容。P0 无实时协作；同一画板同时编辑产生版本冲突时会提示，不能静默覆盖。

学习数据保存在 `.coursex-data/state.json`，图片位于 `.coursex-data/assets/`；API Key 随设置保存在本地状态文件（权限 600）。备份整个 `.coursex-data/`，其中包含密钥，不要作为公开附件分享。它与下载器的认证目录 `.coursex/` 分开。

## 配置问答

页面右上角“模型设置”填写：

1. Base URL：供应商的 OpenAI 兼容接口根地址，通常包含 `/v1`，不要填写完整的 `/chat/completions` 地址。
2. 模型名：供应商提供的准确模型 ID。
3. API Key：该供应商的有效密钥。以后留空保存可保留现有密钥。

服务端通过 `@earendil-works/pi-agent-core` / `pi-ai` 的 Chat Completions 兼容接口调用模型；浏览器只读取“是否已配置密钥”，不读取现有密钥。

请求包含当前课件、最近最多 20 条完整历史消息及本次问题，会发送到配置的模型服务。P0 使用文本上下文，不理解视频声音、屏幕画面或课件图片；视频转写后续接入。回答要求区分课件依据和补充解释，引用为标题或短句，尚不提供自动核验或点击定位引用。过长课件（超过 150000 字符）会明确拒绝直接问答。

## 知识导航与机制实验

页头搜索可以查找全部已保存知识，结果跳转并定位原卡片。主画布支持只读跨章节引用、聚焦全部与整理所选对象间距；新建类型可选择问题、笔记、结论或证据。课程目录可以取得稳定章节链接、下载用于 Learning Hub 的课程导航。操作说明见 [导航说明](navigation.md)。

“＋ Diff 实验”创建 React 18.2.0 keyed 子节点实验，输入、模型版本随卡片保存并支持导出恢复。运行保持草稿状态，适用范围见 [实验说明](keyed-diff.md)。

## tldraw 生产许可与构建

[tldraw 官方许可说明](https://tldraw.dev/community/license) 区分开发与生产。个人非商业项目可申请 hobby 许可，需保留水印；也可使用有效试用或商业许可。开发环境中的许可提示来自 SDK。

取得自己的有效许可后，在 `.env` 写入 `TLDRAW_LICENSE_KEY`，再执行：

```bash
npm run build
npm start
```

许可值是供浏览器验证的公开 key；模型 API Key 则不会返回浏览器。未配置有效 tldraw 许可时，生产画板不可视为可用。字体、图标和翻译通过本地 `/tldraw-assets/` 提供，不依赖 CDN。

## 局域网方案

P0 **无需安装 Tailscale**。默认服务监听 `0.0.0.0:4310`：

1. 部署电脑与访问设备连接同一路由器的普通局域网，不使用开启设备隔离的访客网络。
2. 在其他设备浏览器打开部署电脑的局域网地址，例如本次的 `http://192.168.1.4:4310`。地址可能随网络变化，启动终端会列出网络接口地址；本次 `en1` 对应局域网，虚拟网卡地址不是应分享的 Wi-Fi 地址。
3. 若无法连接，检查 macOS 防火墙是否允许 Node 入站，以及路由器是否开启客户端隔离。可在路由器为部署电脑保留 DHCP 地址，避免 IP 改变。
4. 部署电脑需保持开机且服务运行；电脑休眠或关闭终端服务后将不可访问。

这是用户确认的个人可信局域网、无账号方案。能够访问此服务的局域网设备也能读取和修改学习数据及模型设置；不要配置公网端口转发。

文件由服务端读取，客户端不需要获取课程文件夹权限。P0 的 HTTP 局域网访问覆盖播放、课件、画板与问答；剪贴板等依赖浏览器安全上下文的功能可能需要 HTTPS。

### 未来外出访问

需要外出访问时，推荐各设备加入同一个 Tailscale tailnet，再用 [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve) 将本地服务以私有 HTTPS 暴露给 tailnet。当前不依赖、不安装或配置 Tailscale；不使用会向公网开放的 Funnel。远程网络接入与 HTTPS 的实际配置留在下一阶段。
