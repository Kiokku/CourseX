# 稳定章节入口与知识查找

章节入口为 `/?lesson=<Lesson ID>&view=board`；定位知识卡片为 `/?lesson=<Lesson ID>&card=<Card ID>&view=board`。省略 `view=board` 时保留播放器与课件视图。地址中的 ID 与目录改名无关，服务地址由部署环境决定。刷新、直接打开与浏览器前进/后退都通过相同的保存和加载路径；保存失败时保留当前编辑。已定位卡片可通过“打开已定位卡片”进入详情，既有对象遮挡时仍可访问。未知章节或卡片会显示错误，不会按标题猜测替代目标。

课程目录提供“当前章节固定链接”和“下载本课程导航”。导航 JSON 仅包含当前课程 ID、标题、章节 ID 与原清单编号，不含课程材料、绝对路径、笔记或凭据。原清单 `课程清单.json` 的视频顺序用于恢复路线图中的 001–063；缺失或找不到目录映射时编号为 null，不用当前下载顺序猜测。

在 React Learning Hub 网页点击“连接我的 CourseX”，填写服务地址并导入课程导航。连接仅保存在当前浏览器，可以清除或修改服务地址；不向公共网站上传导航，也不要求 CourseX 开放跨域读取课程库。请选路线所对应的《从0实现 React18》课程；更换课程时应先重新映射路线，不能把任意课程的序号视为相同内容。

## 跨章节引用

主画布“＋ 章节引用”查找其他章节卡片。引用卡片有自己的 ID，target 保存目标 lessonId/cardId，正文为空，不复制目标正文、证据或问答。原卡片仍在原章节编辑，引用卡片显示其当前标题和状态；打开引用所在章节时重新读取目标信息，不提供多人实时同步。

点击“打开原章节并定位”会先保存当前画布，再进入目标主画布、切换到目标页面、选中并聚焦形状。不能新建指向缺失卡片、同章节卡片或另一引用卡片的链接。目标被删除后，既有引用保留并显示失效，可以在画布中删除，不会阻断其他内容保存。

私有导出保留 target；目标未随包输出时记录提示，导入预览也会提示缺失目标。分享包排除目标未包含的引用卡片，避免通过链接标题间接带出被排除的课件摘录。完整课程包可一起恢复两端；只有单侧的包不能凭链接重建另一侧正文。

## 聚焦与整理

页头“查找全部知识”和画布“查找知识”按标题或正文搜索已保存卡片，返回结果只展示标题、状态与课程/章节，不输出完整聊天。结果可打开并定位，失联章节显示不可用。

新建卡片类型可快捷选择问题、笔记、结论或证据；证据卡片直接显示来源输入。保存问答仍从课节问答主动发起。新卡片在附近避开现有对象，不自动重排既有布局。画布提供“聚焦全部”，选中至少两个对象后可“整理所选间距”；整理支持原生撤销，仅改变布局，不修改语义正文或卡片内容时间。分区、框架和连接继续使用 tldraw 原生能力，不强制模板。
