## 已确认

- 本地 Web 学习平台；左侧课程目录、中间视频与课件、右下角悬浮提问、右侧笔记。
- 课程显示名称取 `library/` 下课程文件夹名称，读取已有本地课程资料。
- 个人跨设备使用；课程、笔记、对话和播放进度保存在部署电脑上。P0 不支持多人协作编辑。
- 流式问答使用当前节课课件与对话历史；区分课件依据和模型补充知识。视频转写后置。
- 接入 Pi Agent，支持云端大模型 API。
- 接入 tldraw。画板独立于课程，可随时新建及重新打开编辑；不按课程或课节分配。
- P0 验收同一局域网访问。用户所指网络工具为 Tailscale；外出访问后置。
- NotebookLM Studio 功能留待后续阶段。

## 第二轮已确认

- 云模型先支持 OpenAI 兼容接口，配置 Base URL、模型名和 API Key；Pi Agent 在服务端运行，Key 保存在部署电脑上。
- 继续使用 tldraw，接受许可与水印要求。先完成开发与验证，预留许可配置；由用户申请有效许可后完成生产部署。
- 视频与课件必须同时可见，不能仅以互斥标签页呈现。
- 对话历史按课节保存，切换课节时切换对话，回到原课节时可继续追问。

## 用户已确认的实施方案

- React + TypeScript 前端，Node.js 本地服务负责读取课程、保存学习数据和调用 Pi Agent；沿用现有 Python 下载器。
- 左栏按课程文件夹名称展示，课节优先按已有课程清单顺序排列；无清单时按文件夹名自然排序。缺失视频或课件时显示实际状态。
- 中栏上方视频、下方可滚动课件，问答默认收起在右下角，展开为悬浮窗口；可调整视频与课件区域高度。视频进入画中画时收起页面中的视频和分隔条，退出后恢复。左右栏可收起，画板可展开；窄屏折叠侧栏，学习视图仍保留视频与课件。
- 画板提供新建、命名、列表选择和自动保存；图形与插入的图片保存到部署电脑。P0 不实现多人同时编辑。
- 对话提供连续追问和停止生成。当前课件作为上下文；回答标明课件依据与补充解释。P0 不加入跨课程检索、视频转写或 Studio 生成。
- 学习数据保存在独立本地数据目录，不使用下载认证目录 `.coursex/`；通过服务端读写让其他设备读取相同数据。
- 先面向可信个人局域网，P0 不增加账号体系；模型密钥不返回浏览器。
- 服务监听局域网可达地址，访问 `http://部署电脑局域网IP:端口`；建议在路由器保留部署电脑的 IP，按需放行防火墙。无需 Tailscale；后续外出访问可接 Tailscale Serve。

## 依赖核查

- Pi 当前官方 Agent 包为 `@earendil-works/pi-agent-core`，模型层为 `@earendil-works/pi-ai`：[官方 Agent 文档](https://github.com/earendil-works/pi/blob/main/packages/agent/README.md)。实施时固定实际安装版本。
- tldraw 开发与生产许可不同；生产需有效 license key，hobby 许可保留水印：[官方许可说明](https://tldraw.dev/community/license)。未配置有效许可时不能声称完成生产画板验收。
- [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve) 可用于后续私有远程访问，P0 同局域网访问不依赖它。

## 验收目标

- 从实际 `library/` 列出课程与课节；能打开视频、拖动播放进度并显示课件及本地图片。
- 配置有效模型接口后可依据当前课件连续提问并流式接收回答。
- 独立画板可新建、命名、保存、重新编辑；刷新页面和重启服务后保留；其他设备可读取。
- 对话和播放进度持久化，跨设备读取。
- 提供启动说明和局域网访问方案，并分别记录本机验证与其他设备访问验证结果。
- 未提供有效云模型配置时，记录为问答集成已实现但真实云端调用未验收；不能用模拟流式结果替代真实验收。
