# 学习成果导出 v1

页面右上角“导出”先等待当前画板和卡片保存，再打开导出窗口。选择当前课程、其他课程或全部学习成果，下载 `coursex-export.zip`。个人备份包与分享包使用同一套稳定 ID；用途决定默认内容范围。

## 范围

- **个人备份包**：默认包含卡片、画布布局、主动保存的问答、引用和画布图片。包含课节播放位置与画布视口。
- **分享包**：默认不含问答与图片，排除课件摘录卡片；不包含播放位置或视口。可以主动勾选保存的问答片段与图片。
- 未勾选的问答摘录不会输出为 JSON；其原始对话卡片也会排除。关联摘录的提炼卡片可以保留自己的正文，但去掉未导出的摘录关联。
- 单课程包只含该课程，不含独立草稿。全部学习成果包括独立草稿；课程目录失联但仍有笔记/进度的课节进入 `unassigned/`，避免静默丢失。
- ZIP 不包含课程原视频、完整课件、下载登录状态、模型配置或完整聊天历史。它是学习成果包，不是部署电脑的完整备份。

课件选文通过 Markdown 语法树的可见文字校验，只接受局部 1–2000 字。新卡片默认待验证，并保留课节 ID、课件 SHA-256 与原文片段；正文可修改，来源快照不随之改写。分享包排除这类卡片；需要公开表达时另写自己的说明。

## 目录

目录使用稳定 ID，不随显示标题改名；标题保存在元数据中。

```text
manifest.json
README.md
assets/<图片文件>
courses/<courseId>/course.json
courses/<courseId>/chapters/<lessonId>/chapter.json
courses/<courseId>/chapters/<lessonId>/canvas.json
courses/<courseId>/chapters/<lessonId>/cards/<cardId>.md
courses/<courseId>/chapters/<lessonId>/evidence/<evidenceId>.json
courses/<courseId>/chapters/<lessonId>/conversations/<excerptId>.json
boards/<独立草稿ID>/canvas.json
unassigned/chapters/<失联课节ID>/...
```

`manifest.json` 标注导出协议 `schemaVersion: 1`、生成时间、用途、范围、实际输出的摘录 ID、文件索引、图片大小与摘要、处理提示。这个版本号属于导出协议，不代表原始 state.json 可以直接拿来导入。

卡片 Markdown 使用 JSON 值格式的 YAML frontmatter 保存 ID、课节、类型、状态、来源和内容时间；标题与正文可在编辑器之外直接阅读。画布 JSON 保存原生 tldraw 文档结构；本地图片引用改成包内相对路径。外部资源保留引用，不替用户下载第三方文件。图片缺失或路径越界时导出失败，不生成悄悄缺图的包。

## 一致性与 Git

后端等待已排队写入，克隆一次已提交的学习状态；导出不再反复读取变化中的 state。图片使用不可变上传文件，课程原文件不纳入包。课程扫描仅提供 ID、显示标题和章节顺序。

文件名和对象 ID 稳定；对象属性按字典顺序输出、文件和索引使用固定顺序（课程章节保留原顺序），正文统一 LF。ZIP 文件顺序与压缩时间固定。无修改时重复导出，只有 manifest 的 exportedAt 可以变化；移动图形不会改写卡片 Markdown。除 manifest 外，JSON/Markdown 中不写入本次导出时间。

分享或取消资源时，会同时移除相应图形、无用资源和连接，避免留下指向已排除内容的悬空关系；书签可以保留链接。选中的问答在提交时已不存在或不在范围内，会要求重新打开导出窗口。

## 隐私边界

导出使用显式内容字段，不复制整个状态文件。文本中发现已配置的模型密钥会替换；URL 的账号密码和敏感查询参数会清理；常见本地绝对路径与敏感元数据字段会省略。manifest 记录处理类型，不记录被删掉的秘密值。

这不能识别所有未知凭据，也不能判断用户笔记或图片是否复制了私人信息、完整课程材料或屏幕内容。自由画布文字与个人笔记仍会输出，公开前必须自行检查。图片按原始字节复制，不提供图片隐私识别或去除图片元数据的保证。不要把“分享包”当成自动通过公开内容审查。

同版本包可通过[导入恢复](import.md)预览并新增无冲突的章节与草稿；已排除或清理的内容无法补回。暂不支持自动 Git 同步或发布。完整私有数据备份仍请保留部署电脑的数据目录；其中可能含密钥，不用于公开分享。
